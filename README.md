## 🇬🇧 English

**FelixSecure** helps you protect your privacy by encrypting your personal files. With its simple interface, you can browse your files, choose which ones to encrypt, and decrypt them whenever you need them.

### ✨ Features

- 🖼️ Browse image and video files
- 📄 View documents, audio files, and archives
- ☑️ Select files individually
- 🔒 Encrypt files with a password
- 🔓 Decrypt your files whenever needed
- 🌐 Automatically uses Turkish or English based on your system language

Get the latest version from the **[GitHub Releases page](https://github.com/felixpatron/FelixSecure/releases/latest)**.

3. Run the EXE. No additional installation is required.
